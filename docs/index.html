Userscript浏览器用户脚本

🚀安装指南

① 用户脚本（浏览器）

1
浏览器安装 Tampermonkey（或 Violentmonkey）扩展。tampermonkey.net ↗
2
打开 脚本 Raw 地址 ↗，Tampermonkey 会自动弹出安装页，点安装。
3
打开任一支持的网盘页面，右下角出现悬浮球；Alt + D 快捷开关面板。首次使用先到设置里配置下载器地址并测试连接。

② Gopeed 原生扩展

1
打开 Gopeed → 扩展页面 → 从 URL 安装，粘贴：https://github.com/CZY1326/CloudLink-Master-Pro#gopeed-extension
2
安装后打开扩展开关，并在扩展设置里填入夸克 Cookie（必填，抓法见下方教程）。
3
重启 Gopeed → 新建任务 → 粘贴分享链接（如 https://pan.quark.cn/s/xxxx?pwd=abcd）→ 弹出解析窗勾选文件下载。
💡扩展解析失败时 Gopeed 会静默回退为普通下载——如果你下载到的是一个 .html 分享页而不是文件本身，几乎都是 Cookie 缺失或失效，按下面教程重新抓一份即可。

🍪Cookie 抓取教程

夸克已强制登录才能解析直链和下载，扩展必须配置登录 Cookie。以下方法同样适用于 UC 网盘（drive.uc.cn）。

方法 A：Cookie-Editor 扩展一键抓取 推荐 · 小白友好

开源工具（GitHub ↗），点几下按钮就能拿到整串 Cookie，不用碰开发者工具。Chrome / Edge 通用。
1
安装 Cookie-Editor 浏览器扩展 ↗（Chrome 应用商店，Edge 会自动提示安装）。
2
登录 pan.quark.cn ↗，点击浏览器工具栏上的 Cookie-Editor 图标（饼干形状）。
3
点右下角的 Export 按钮——下拉菜单里选择 Header String 格式（⚠️ 不要选 JSON），整串 Cookie 会自动复制到剪贴板。
4
粘贴到 Gopeed 扩展设置的 夸克 Cookie 输入框 → 保存 → 重启 Gopeed。UC 网盘同理（Cookie-Editor 里选 Header String 后填入 UC Cookie）。
⚠️Export 一定选 Header String：JSON 格式是给开发者备份用的，扩展只认 name=value; name=value 这种分号分隔的字符串。

方法 B：F12 开发者工具手动抓取

1
用 Chrome / Edge 登录 pan.quark.cn ↗（建议无痕窗口，避免多余 Cookie 干扰）。
2
按 F12 打开开发者工具，切到 网络（Network）标签页。
3
刷新页面，在请求列表里随便点一个请求（如 list、token 等），找到 请求标头（Request Headers）。
4
找到 Cookie: 那一行，右键 → 复制值（或手动全选整串）。必须是完整整串——从 xlly_s=1; 开始、以分号分隔、包含 __puus / __pus / __kp 等字段。
5
粘贴到 Gopeed 扩展设置的 夸克 Cookie 输入框 → 保存 → 重启 Gopeed。
⚠️Cookie 等同于登录凭证，不要分享给任何人。夸克的 __puus 字段会不定期轮换，解析突然失效时重新抓一份即可。

💬常见问题

Q会不会有安全风险？数据会上传吗？
全部逻辑本地运行：无广告、无授权码、无远程配置服务器、不采集任何数据。唯一的外部请求是你自己网盘的官方接口与下载器地址。Cookie 只保存在本地（浏览器脚本存储 / Gopeed 数据库）。
Q用户脚本和 Gopeed 扩展要二选一吗？
不需要，两者独立工作：脚本适合「已经在浏览网盘页面」的场景（批量解析整个目录、多出口推送）；扩展适合「手里只有一条分享链接」的场景（直接在 Gopeed 里解析下载）。
Q支持哪些下载器？
用户脚本出口：Aria2 / Motrix RPC（批量推送 + 子目录还原）、Gopeed、IDM、ABDM、cURL、BitComet、aria2c 命令行、网页下载、增强下载。Gopeed 扩展则直接生成 Gopeed 任务。
Q分享链接需要提取码怎么填？
扩展会自动从链接尾部识别提取码，三种写法都支持：https://pan.quark.cn/s/xxxx?pwd=abcd、...#提取码:abcd、...#密码 abcd。
